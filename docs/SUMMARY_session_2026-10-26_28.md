# 세션 정리: Pleos 개념 앱 기획 (2026-10-26 ~ 28)

> 이 세션의 흐름·결정·결론을 한 장에 정리. 세부 근거는 각 문서 참조.
> - 기준 개념: `CONCEPT_v3_integrated.md`
> - 인계·규칙: `HANDOFF_pleos_concept.md` (3절 판별 기준, 3.5절 생성 규칙, 11~12절 진행·다음 할 일)

## 1. 결론 요약
- **현재 최선 개념: "가족은 편히 자고, 운전자는 깨어 있게"** (v3). 이미 하는 이동에서 좌석별로 자는 사람의 환경을 만들고, 운전석은 각성을 유지하며, 운전자 상태를 평소 대비로 감시한다. 사용자 평가: "괜찮은 아이디어".
- **도로·날씨 쪽은 선점됨.** 군집이 드러내는 도로·날씨 장(급제동 지도, 와이퍼 강수, 노면 미끄러움)은 혼다·구글·도요타·NIRA가 이미 연구·상용화. 비어 있는 곳은 **차 안의 사람**.
- **아이디어 생성 규칙 채택.** 새로움은 "서로의 약점을 메우는 조합"에서 나온다. 규칙 6개 + 선행 검색 필수.
- **사용자 환경:** 에뮬레이터·SDK 미설치. 앱 구현보다 개념 우선.

## 2. 흐름
| 단계 | 내용 | 결과 |
|---|---|---|
| 1 | HANDOFF 6번 열린 결정 | 4번(주차 미기후 주력 + 트렁크 지도 2차) 선택 |
| 2 | 주차 미기후 효과 크기 | 여름 냉방 차 0.1~0.3 kWh(한계선), 겨울 난방이 더 큼 |
| 3 | SDK 신호 확인 | 외기온·공조 전력 없음. 실내 온도(좌석별 °C) 있음. SOC 정수 % → 에너지 잔차 폐기, **실내 온도 곡선(ΔT0)으로 전환** |
| 4 | 군집 복원 시뮬레이션 | 클러스터당 5~8회(기준)~30회+(비관). 차량 효과는 교차 방문으로 분리 가능(집 앞 전용 자리도 보정됨) |
| 5 | 에뮬레이터 주입 절차 | inject-vhal-event 절차 작성. 사용자 미설치로 실행 안 함 |
| 6 | "개념 먼저"로 전환 | 문헌 기반 효과 크기: 햇볕-그늘 약 9 °C, 모델 오차 약 0.5 °C → 물리적으로 가능, 차량 효과·센서 의미가 관건 |
| 7 | 날씨 확장 논리 검토 | 차량 날씨 관측은 연구·상용 많음, 기관용 → 보류 |
| 8 | PEX(확장 장치) 전제 | 센서를 달 수 있으면 SDK 공백 해소 |
| 9 | 건강 방향 | "평소의 나": 운전 수행의 개인 내 변화. 시계는 몸, 차는 머리·손. 인지 나이는 기각(개인차 > 나이 효과) |
| 10 | 수면 방향 | 영아 재우기 드라이브 → **가족 수면으로 확장 (v3)**. 좌석별 환경 + 운전석 각성 구역 + 도착 맞춤 깨우기 |
| 11 | v3 확장 모듈 | CO₂ 추정(✔), 좌석별 멀미(△), 가족 상태 휴식 타이밍(△) |
| 12 | 방향 전환 탐색 | 주차 휴식·차 이력서·부모 안부(보관), 주차장 난이도(기각), 트렁크 물건(기각, 뻔함), 도로 완화·날씨 완화(모두 v3로 수렴) |
| 13 | 생성 규칙 정리·시험 | 규칙으로 5개 생성 → 2개 유망(충전 휴식 회복, 개인 야간 페널티). 규칙 채택 |

## 3. 현재 개념 (v3) 구조
| 모듈 | 역할 | 상태 |
|---|---|---|
| 좌석별 수면 구역 (주인공) | 자는 사람 자리만 온도·풍향·열선·조명 조절 | 열선·통풍 ✔ 개별, 공기 온도 △, 빛 △ |
| 운전석 각성 구역 + 평소의 나 (안전장치) | 운전석은 시원·밝게, 소리는 운전석만. 운전자 반응을 평소 대비 감시 | 소리는 현대·기아 SSZ 또는 헤드레스트 스피커 |
| 도착 맞춤 깨우기 | 도착 15~20분 전부터 빛·온도 상승 | 수면 단계 추정은 거침 |
| 부드러운 운전 가이드 | 자는 사람 있을 때 급가감속 줄이기 | 군집 진동 지도 사용 |
| 주차 미기후 (입력) | 출발 전 실내 온도 → 예약 공조 | 시동 전 센서 유효성 미확인 |
| CO₂ 추정 (확장) | 인원 × 내기 순환 × 팬 × 시간 → 운전자 졸음 방지 | ✔ SDK로 가능. 3명이면 약 10분에 2,000 ppm 상승. 현행 고정 타이머(약 30분)보다 나음 |
| 좌석별 멀미 (확장) | 0.2 Hz 좌우 흔들림 × 개인 민감도 | △ 속도·콜백 주기 확인 필요 |
| 가족 상태 휴식 타이밍 (확장) | 모든 모듈 출력 통합 | △ 휴리스틱 |
| 영아 특수 모드 | 카시트 시간 규칙(3개월 미만 30분, 2세 미만 2시간) | 차 안 영아 근거 없음 |

**진동은 나눌 수 없다** → 4~7 Hz는 운전자도 졸리게 함(RMIT) → 운전자 감시 필수.
**등받이를 눕히라고 권하지 않음** → 서브마리닝 위험(NHTSA).

## 4. "평소의 나" 요지
- 매일 같은 시험(출퇴근 운전)으로 오늘의 나를 평소의 나와 비교.
- 지표: 반응(앞차 감속 → 브레이크), 정밀(조향 보정·차로 흔들림), 꾸준함.
- 군집은 "오늘 이 구간이 원래 어려웠나"를 빼는 보정.
- 근거: 피로 시 반응 +16.7%, 실주행으로 우울 AUC 0.84·전임상 알츠하이머 AUC 0.96, 정신 피로 시 HRV가 수행과 어긋남(시계의 빈틈).
- 표현 규칙: 진단·원인 단정 금지, 타인·나이 비교 금지, 데이터는 차 안·본인만.
- 유망 확장: 장소 유형별 개인 약점 × 오늘 컨디션, 충전 휴식 회복 효과, 개인 야간 페널티.

## 5. 아이디어 생성 규칙 (채택)
1. 도메인이 다른 신호 2개 이상
2. 그중 하나는 차에만 있는 신호
3. 군집은 평균이 아니라 보정 장치
4. 결과가 어느 요소 하나로는 나오지 않는 값
5. 각 요소가 다른 요소의 약점·부작용을 막음
6. 선행 검색 필수
- 주의: 운전 행동("평소의 나") 변형으로 쏠림 → 다른 대상도 의도적으로 생성.

## 7. 확인된 SDK·환경 사실 (이 세션)
- Vehicle SDK 19개 클래스. **없음:** 외기온, 배터리 온도, 공조 전력, 속도, 시동·기어, 운전자 상태.
- **있음:** 실내 온도 `getHvacTemperatureCurrent(SeatArea)` °C(실내 온도로 문서 확인), SOC 정수 %, 전비 km/kWh(순간값은 deprecated 예정), 조향각 −540~540°, 브레이크 페달 0~100%, 좌석 점유, 도어, 공조 상태·설정, 좌석 열선·통풍, 핸들 열선, 조명(앰비언트 밝기·색), 와이퍼, Odometer.
- ADAS SDK: 차 바깥 정보(객체·차선·주차 공간), 상세 문서 미확인. STT: 텍스트만. NaviHelper: 목적지·경유지·경로, ETA·시설 검색은 문서에 명시 없음.
- Virtual Console: 실내 온도·외기온 입력 카드 없음 → 에뮬레이터로는 앱 로직만 검증 가능.
- Gleo AI: 발화자 좌석 식별(앱 접근 미확인). 현대·기아 SSZ(좌석별 음향, 양산 차종 미확인). PEX 상세 사양 공개 자료 없음.

## 3. 눈에 띄는 것
1. **좌석 위치 11종**이 가장 큰 미사용 덩어리. 콜백이 있어 변화 시점까지 기록 가능.
2. **좌석별 독서등**: 수면 구역에서 "깨어 있음"의 직접 신호.
3. **스마트 글라스·블라인드**: 가벽의 출력 장치. 탑재 차종 확인 필요.
4. **방향지시등·크루즈**: 운전 행동인데 평소의 나에 아직 안 들어감.

## 4. 사용자 제안 검토 (2026-11-03)
| 제안 | 판정 | 근거·선행 |
|---|---|---|
| 좌석 위치 기억 → 관절·근육 이상 경고 | **✔ 채택(평소의 나 "자세" 축, 변화 알림)** | 실주행 연구: 불편해지면 앉은 자세를 자주 고침(PMC8594853). 자세 교정 추천 특허(US11724703: 좌석 각도·위치로 바른 자세 권고), 압력 센서 지능형 좌석(US20220274508)은 선행. **새 부분 = 바른 자세 강요가 아니라 본인이 고른 자세의 장기 추세(점점 세움·높임·앞으로) + 주행 중 고쳐 앉는 횟수 증가.** 군집으로 같은 차종·시트 기본값 제거 |
| 가족 운전자별 설정 자동 조절 | ✘ 기능으로는 이미 있음(좌석 메모리 `selectSeatMemory`, 키별 프로필) | **대신 "누구의 데이터인가"를 나누는 기반으로 필수.** 모든 평소의 나 계열이 사람별 귀속을 전제 |
| 좌석별 조도 | ✘ SDK 없음 | PEX 소형 조도 센서로 가능(저가) |
| 안전벨트 당김 정도 | ✘ SDK 없음 | 체결 여부·벨트 높이만 있음. 벨트 높이는 어깨 높이 근사(정적) |
| 상향등·안개등 사용 빈도 × 군집 → 야간 시야 | **✔ 유망** | 고령 운전자는 상향등을 3배 더 씀(100 km당 24.2분 vs 4.6분) = 시야 저하를 스스로 보상(UMTRI). 사용률은 시골·마주 오는 차·커브에 크게 좌우 → **같은 구간·시간 군집으로 길 탓 제거 시 개인 보상 지수.** 주의: 자동 상향등 차량은 스위치 상태(`getHighBeamLightSwitch`)가 AUTO면 제외. 안개등은 습관 잡음이 커서 보조 |

- 상향등 지수는 10.13의 "빛 민감도"·10.10의 "야간 페널티"와 합쳐 **시야 모듈**로: 운전 수행(평소의 나) + 보상 행동(상향등) 두 축. 본인은 "잘 보인다"고 해도 손이 먼저 보상함 → 핵심 원칙 일치.

### 4.1 채택: 평소의 나 확장 (2026-11-03, 사용자: "경고가 아니라 평소와 달라진 알림이니 괜찮다")
| 축 | 신호 | 보는 것 | 출력 예 |
|---|---|---|---|
| 수행 (기존) | 조향각, 브레이크 | 반응·정밀·꾸준함 | "평소보다 반응이 늦습니다" |
| **자세 (신규)** | 좌석 위치 11종 콜백 | 장기 추세(등받이 세움·높이·앞뒤·요추), 주행 중 고쳐 앉기 횟수, 고쳐 앉기 시작 시점(주행 몇 분째) | "최근 3주 등받이를 평소보다 4° 세워 앉고, 운전 중 자세를 2배 자주 고칩니다" |
| **시야 보상 (신규)** | 상향등 스위치·상태(수동만) + 군집 | 같은 구간·시간 대비 상향등 사용 | "같은 길에서 상향등을 평소보다 자주 켭니다" |

- 표현 규칙 그대로: 원인·질병 단정 금지, 사실 + 질문형 맥락("허리가 불편하신가요?").
- 사람별 귀속: 좌석 메모리 슬롯 + 운전 패턴으로 운전자 구분(가족 공용 차 전제).
- 군집 보정: 자세는 같은 차종·시트 기본값, 상향등은 같은 구간·시간대.

### 5.1 사용자 판단 (2026-11-03)
- 벨트 체결 시간: **기각.** 바로 매는 사람이 많다고 단정 못 함 → 오측치 과다.
- 경고 해소 기간·하이패스 음량: **기각.** 과적합에 가까움.
- 방향지시등: 켜는 비율·누락 방식은 부정적. **조작 순서 타이밍으로 재설계 시 채택 후보.**
  - 회전 한 번 = 깜빡이 ON → 브레이크 시작 → 조향 시작(→ 브레이크 해제)의 시간 간격 묶음. 사람별 분포를 기준선으로, 간격의 흔들림·순서 뒤바뀜(조향 후 깜빡이)을 평소의 나 "계획" 축으로.
  - **제약: Vehicle SDK에 가속 페달 신호 없음**(Brake 클래스는 브레이크 페달만). 가속 재개는 브레이크 해제 시점으로만 대체.
  - 회전 감지는 조향각 크기, 차로 변경은 판별 어려움 → 회전(교차로)만 대상.

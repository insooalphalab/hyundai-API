# 통합 개념 v3: 가족은 편히 자고, 운전자는 깨어 있게

> **앱 이름 (2026-11-04 확정): 시트룸 — 좌석마다 나만의 방.** 검토 후보: 결·안쪽 날씨·솔기·몸말(너무 간접적이라 기각), 1석1방·자리마다·칸칸, 윈도우시트(방을 나눈다는 그림이 없고 동명 앱 다수라 기각).

> 2026-10-27. v2(영아 수면 드라이브)를 가족 전체로 확장. 경과: 주차 미기후(NOTES_parking_microclimate.md) → 평소의 나(CONCEPT_baseline_me.md) → 영아 수면 드라이브 → 가족 수면.
> 표기: ✔ 문헌·문서 확인, △ 일부 근거/추정, ✘ 근거 없음·불가.
> **상태: 사용자 평가 "괜찮은 아이디어" (2026-10-27). 확장 장치(PEX)로 좌석별 환경을 만드는 방향 포함. 이 방식(모듈을 서로 보정하며 확장)으로 계속 키워 갈 것.**
> **핵심 원칙 (사용자, 2026-10-28): 진짜 맞춤은 본인의 판단(자기 보고·선택)이 아니라 몸이 실제로 반응한 지점(운전 행동·생리 신호)을 근거로 한다.** 근거: 정신 피로 때 심박변이도가 수행 저하와 어긋남, CO₂ 노출 때 주관적 졸림은 그대로인데 생리 반응만 변함 — 사람의 느낌과 몸의 반응은 다를 수 있음. 분야별 연구·기술과 실현 단계(졸음은 양산, 음주·저혈당·인지 저하는 실차 연구, 스트레스·인지 부하는 실험실): **`EVIDENCE_driver_state_sensing.md`**.

## 1. 한 문장
이미 하는 이동에서, 좌석별로 자는 사람은 편히 자게 하고 운전석은 깨어 있게 한다. 운전자 상태 감시(평소의 나)가 안전을 닫고, 차량 실내·외부 센싱(미기후, 노면 진동)이 입력이 된다.

**v2에서 바뀐 점:** "재우려고 드라이브" → "가는 길에서 잘 자게". 대상 영아 → 가족 전체(동승석·뒷좌석·어린이). 영아는 특수 모드.

## 2. 모듈과 연결
| 모듈 | 역할 | 혼자서의 한계 | 다른 모듈이 채워 주는 것 |
|---|---|---|---|
| **좌석별 수면 구역** (주인공) | 자는 사람 자리만 온도·풍향·열선·조명을 수면용으로 | 같은 차 안의 운전자까지 졸리게 할 수 있음 | 운전석 각성 구역 분리 + 평소의 나 감시 |
| **도착 맞춤 깨우기** | 도착 예정 시간에 맞춰 15~20분 전부터 빛·온도를 서서히 올림 | 수면 단계 추정이 거침 | 좌석별 수면 감지 시간 + NaviHelper ETA |
| **운전석 각성 구역 + 평소의 나** (안전장치) | 운전석은 시원·밝게 유지, 운전자 반응을 평소 대비로 감시 | 점수 하락 원인 해석이 어려움 | 수면 구역 운영 여부·진동 노출량으로 해석 보정 |
| **부드러운 운전 가이드** | 자는 사람이 있을 때 급가감속·급커브 줄이도록 피드백 | 운전자 부담 | 군집 진동 지도로 덜 흔들리는 경로 제안 |
| **주차 미기후** (입력) | 출발 전 실내 온도 예측 → 예약 공조 | 개인 가치 약함 | 출발 시점부터 수면 구역 온도 확보 |
| **군집 진동 지도** (입력) | 구간별 노면 진동·커브·가감속 패턴 | 단독으론 도로 데이터 | 경로 제안 + 평소의 나 구간 난이도 보정 |
| **경로 성격 선택** (부드러운 운전 가이드 확장) | 같은 목적지에 편안한 길 / 즐기는 길 / 빠른 길. 차 안 신호로 "그 길에서 몸이 실제로 어땠나"를 학습 | 경로 3모드 자체는 선행 있음 | 평소의 나(오늘 컨디션)·동승자 상태(수면·멀미)가 모드를 고르고, 군집 진동·멀미 지도가 "편안한 길"을 실측으로 정의 |
| **영아 특수 모드** | 영아용 코스(필요 시), 카시트 시간 규칙 | 차 안 영아 근거 없음 | 위 모듈 전부 재사용 |

공통 계산: 개인 기준선 대비 편차 → 같은 구간·시간대 군집 편차를 빼서 "내 탓/이 사람 탓"만 남김.

## 3. 사용 장면
**A. 주말 귀성(2시간, 뒷좌석 아이 둘 + 동승석 배우자)**
1. 출발 전: 주차 자리 열 노출 + 외기 → 예약 공조.
2. 30분 뒤 뒷좌석 두 명 수면 감지(또는 "잠들었어요" 입력) → 뒷좌석 구역: 따뜻하게, 풍량 낮춤, 앰비언트 어둡게. 운전석 구역: 시원하게, 밝게 유지.
3. 운전자에게 "뒤에서 자는 중, 부드럽게" 가이드. 덜 흔들리는 경로 후보 제안.
4. 운전자 반응이 평소보다 떨어지면 휴게소 권고.
5. 도착 20분 전부터 뒷좌석 빛·온도 서서히 올림 → 깊은 잠 중 기상 회피.

**B. 퇴근길 동승자 낮잠(30분)** — 20분 안팎에서 깨우도록 도착 맞춤 조정.

**C. 영아 특수 모드** — 월령별 시간 상한, 도착 즉시 카시트에서 꺼내기 안내, 필요 시 재우기 코스.

## 3.5 좌석별 개별 환경: 무엇을 나눌 수 있나

| 채널 | 기본 차량 | SDK | 확장(PEX) 설치로 보완 | 판정 |
|---|---|---|---|---|
| 몸에 닿는 열(열선·통풍·핸들 열선) | 좌석별 독립 | `setHvacSeatTemperature`, `setHvacSeatVentilation`, `setHvacSteeringWheelHeat` | 뒷좌석에 없으면 12 V 열선·통풍 방석(시판품 존재) | ✔ 완전 개별 |
| 공기 온도 | 2·3존 공조(차종별) | 구역별 `setHvacTemperature`, 풍향·풍량 | 헤드레스트·시트백 소형 송풍기(시판품 존재) | △ 공기가 섞여 실제 차이 작음(추정 1~3 °C) |
| 소리 | 현대·기아 SSZ(분리 음향 존, 2018 발표, 양산 차종 미확인) | Vehicle SDK 없음 | 헤드레스트 근거리 스피커 모듈 | ✔ 운전석만 음악·라디오·음성 비서, 뒷좌석은 조용히 |
| 빛 | 좌석별 독서등, 앰비언트 구역 지원 미확인 | Light API | 소형 조명, 뒷창 차광(수동·전동) | △ 전동 차광은 장착이 큼 |
| 진동·흔들림 | 차 전체 공유 | 없음 | 방석 감쇠는 효과 미미(추정), 능동 시트 서스펜션은 액세서리로 불가 | ✘ 나눌 수 없음 → 운전자 감시로 대응 |
| 수면 감지 | 일부 차종 아동 감지 레이더(접근 미확인) | 없음 | 60 GHz 레이더 모듈(호흡·재실 감지, 소형·저전력) | ✔ 기술적으로 가능 |
| 노면 진동 측정 | 없음 | 없음 | 가속도 센서 모듈 | ✔ |
| 운전자 시선·졸음 | 일부 차종 운전자 카메라(접근 미확인) | 없음 | 운전자 모니터링 카메라(상용 차량용 시판품 존재) | ✔ 단 생체정보 |

**운전자 "편안함" = 각성 유지형 편안함.** 운전석은 약간 시원·통풍, 주변 밝기 유지, **소리는 운전석만 켬**(지금은 아이가 자면 음악을 끄고 단조롭게 감 → 졸음). 진동은 공유되므로 평소의 나 감시 유지, 동승자가 모두 잘 때 휴식 권고 기준 강화.

**확장 설치 시 추가 안전 규칙**
- 접촉 열: 자는 사람은 뜨거움에 늦게 반응 → 온도·시간 상한, 영아·어린이 더 낮게(저온 화상).
- 장착물: 충돌 시 날아가는 물체가 되지 않게 고정, 에어백 전개 구역(시트 측면·헤드레스트 주변) 회피.
- 차광: 운전자 시야를 가리는 창(앞·운전석 측면)은 제외.
- 레이더·카메라: 영상은 장치 안에서 처리, 특징값(수면 여부·호흡수)만 전송. 60 GHz 차량 내 사용 국내 전파 규정 확인 필요.

**PEX 공개 정보 한계:** "장착 즉시 전원·통신 연결, 표준 HW/SW 인터페이스, 보안 인증, BLE 지원"(사용자 제공 설명)과 Pleos SDV 표준 포럼의 플러그앤플레이 프레임워크 논의 외에, 장착 위치·전원 용량·통신 대역·앱 제어 범위는 공개 자료를 찾지 못함. 열선 방석(수십 W)은 전원 용량, 근거리 스피커는 오디오 대역(BLE 오디오 가능 여부)이 관건.

## 3.6 확장 모듈 후보 검토 (2026-10-27)

| 모듈 | 연결점 | 효과 크기 | SDK로 되는 것 | 막히는 것 | 판정 |
|---|---|---|---|---|---|
| **A. 실내 CO₂ 추정** (센서 없이) | 가족 수면용 내기 순환 → CO₂ 누적 → 운전자 졸음. 수면 모듈의 부작용 차단 | 내기 순환 시 1명 1.43 ppm/s, 3명 3.52 ppm/s, 3명이면 약 8분에 2,500 ppm 초과 사례 ✔. 인지 효과는 엇갈림(50명: 1,400 ppm↑에서 위반·피로 증가 / 60명: 주관적 졸림 차이 없음, 생리 반응만) △ | 좌석 점유(인원), 내기 순환 상태, 팬 단계, 시간 → 질량 수지 추정. 전환은 `setHvacRecirculation` | 내기 시 외부 공기 유입률이 차·속도마다 **시간당 3~23회**로 약 8배 차 → 차종 보정에 실측 필요(PEX CO₂ 센서 장착 차 일부로 보정하는 2단 구조). 제어 SDK "준비 중" | **✔ 가능.** 보정 전에도 "인원 비례 타이머"가 현행 고정 타이머(저온 시 약 30분 후 자동 환기)보다 나음: 3명 이상이면 약 10분 안에 2,000 ppm 상승 |
| **B. 좌석별 멀미 관리** | 진동 지도·부드러운 운전 가이드·좌석별 바람 재사용 | 약 0.2 Hz 좌우 흔들림에서 12명 중 12명 중간 이상 메스꺼움(0.1 Hz 8명, 0.4 Hz 7명) ✔. 실도로에서 좌우 가속 크고 경로 예측 어려울수록 심함 ✔ | 조향각 + 속도 → 좌우 가속 추정(≈ 속도² × 곡률). 경유지 추가로 경로 유도(NaviHelper) | 속도 출처(FusedLocation 상태), 조향각 콜백 주기, 사용자 지정 경로 불가(경유지로만), 좌석별 "속 안 좋아요" 입력(Gleo 좌석 식별 접근 미확인 → 화면에서 좌석 선택으로 대체), 주행 중 안내는 음성(TTS "준비 중") | **△ 조건부.** 핵심 신호(조향각)는 있음. 속도·콜백 주기 확인 필요 |
| **C. 가족 상태 기반 휴식 타이밍** | 모든 모듈 출력 통합: 운전자 반응, 수면 경과, 멀미 누적, CO₂ 추정 | 각 모듈 근거 재사용 | 휴게소를 경유지로 추가(NaviHelper) | 도착 예정 시간·주변 시설 검색은 문서에 명시 없음 → 한국도로공사 휴게소 공공데이터로 대체(존재 여부 확인 필요). 수면 단계 예측은 경과 시간 휴리스틱(20~60분 구간 깨우기 회피)뿐 | **△ 휴리스틱 수준으로 가능** |

추천 순서: A → B → C. A는 SDK 신호만으로 시작 가능하고 가족 수면의 부작용을 직접 막음.

## 3.7 경로 성격 선택 모듈 (2026-10-28)

**한 줄:** 같은 목적지라도 오늘의 나와 지금 탄 사람에 맞춰 편안한 길 / 즐기는 길 / 빠른 길을 고른다. 학습 근거는 사용자의 선택이 아니라 그 길에서 **몸이 실제로 보인 반응**.

| 구성 | 내용 | 신호 |
|---|---|---|
| 길의 성격 | 곡률·경사(지도 데이터), 노면 진동·0.2 Hz 좌우 흔들림(군집 지도), 신호·정체(내비) | 오픈스트리트맵 등, PEX 가속도 센서, 군집 |
| 몸의 반응 학습 | 그 구간에서 조향이 부드러웠나, 브레이크 재조정이 늘었나, 평소 대비 반응이 떨어졌나, 다음에 또 그 길을 골랐나 | `registerSteeringWheelAngle`, `registerBrakePedalStatus`, 평소의 나, 경로 기록 |
| 모드 선택 규칙 | 컨디션 낮음 → 편안한 길 권장 · 뒤에서 수면 중 또는 멀미 민감 동승자 → 편안한 길 고정 · 비·야간 → 즐기는 길 끔 · 급할 때 → 빠른 길 | 평소의 나, 좌석 점유·수면 감지, 와이퍼, 시각 |
| 경로 적용 | 앱이 자체 계산한 경로를 NaviHelper **경유지 추가**로 유도(경로 직접 입력 불가) | NaviHelper |

**선행 사례**
- 굽은 길 경로: Calimoto(빠르게/고속도로 제외/굽은 길/아주 굽은 길 4모드), Kurviger(굽은 정도 슬라이더) — 오토바이 앱
- 개인 맞춤 경로 학습: 마이크로소프트 TRIP(2006, 과거 GPS 기록으로 선호 학습)
- 곡률과 편안함을 반영한 경로 계획 특허(US8306732)
- → 경로 3모드 자체는 새롭지 않음. 새로운 부분은 **"선택이 아니라 몸의 반응으로 학습" + "오늘 컨디션·동승자 상태로 모드 결정"**.

**안전 규칙**
- 재미는 속도가 아니라 길의 모양(굽은 길, 고갯길, 경치)으로만 정의. 제한 속도 안에서.
- 스릴 추구 성향이 강한 운전자는 법규 위반이 잦다는 연구 → 컨디션 저하·동승자 수면·비·야간에는 즐기는 길 끔.
- 이름은 "도파민"보다 "드라이빙 즐기는 길"처럼 속도를 연상시키지 않게.

**막히는 점:** 경로 직접 입력 불가(경유지로만), 속도는 FusedLocation 의존, 곡률·경사는 별도 지도 데이터 필요.

## 5. 안전 규칙 (개념의 일부)
- **등받이를 눕히라고 권하지 않는다.** 눕힌 자세는 충돌 시 서브마리닝(벨트 아래로 미끄러짐) 위험 증가(NHTSA 인체모델 연구 등). `moveSeatBackrestAngle`은 수면 기능에 쓰지 않는다. 수면 수단은 온도·빛·운전 부드러움.
- **운전석은 수면 구역에서 분리.** 따뜻함·어두움·저주파 진동이 운전자에게 번지지 않게.
- **운전자 반응 저하 시 휴식 권고**(평소의 나). 동승자가 모두 잘 때 더 엄격하게.
- **영아:** 3개월 미만 한 번에 30분 이하, 2세 미만 2시간 이하(영국 NHS 지역 지침, 단일 국가 기준 없음). 도착 즉시 카시트에서 꺼내기. 신생아·미숙아 대상 제외 검토.
- 평소의 나 표현 규칙: 진단·원인 단정 금지, 타인·나이 비교 금지, 데이터는 차 안·본인만.

## 10.6 기각: 주차장 난이도 지도 (공간 방향, 2026-10-27)
- 내용: 차 크기별 주차장 난이도(핸들 끝까지 꺾기, 전진·후진 왕복 횟수, 주차 시간)를 군집으로 지도화.
- 근거: 문콕 보험 접수 2019년 4,782건 → 2023년 15,200건(한 손보사), 대형차 비중 8.9% → 25.1%, 주차면 폭 2.3→2.5 m는 신설만. 공간 1 m 증가 시 평행주차 기동 시간 최대 29~31% 감소.
- 기각 사유: 도요타 특허 US10475342(2017, 발화 + 전진·후진 전환 횟수 + 차 크기 단계별 난이도)가 핵심을 선점. 변형(내릴 공간·문콕 예측, 기계식 주차 적합성)도 **확장성 부족**(사용자 판단).
- 함께 기각: 타이어 마모 추정(주행거리계 vs GPS, 새 타이어 대비 약 1~1.5%) — 굿이어 등 간접 마모 추정 특허 다수.

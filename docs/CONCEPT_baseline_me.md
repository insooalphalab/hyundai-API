# 개념 v1: 평소의 나 (운전 기반 개인 내 변화 감지)

> 2026-10-27 정리. 주차 미기후에서 방향 전환. 근거·검토 경과는 대화 기록 및 NOTES_parking_microclimate.md 참조.

## 한 문장
차는 매일 같은 시험(출퇴근 운전)을 본다. 오늘의 나를 평소의 나와 비교한다.

## 시계와의 차이
| | 시계 | 평소의 나 |
|---|---|---|
| 재는 것 | 몸의 상태(심박, HRV, 수면) | 머리와 손의 수행(반응, 정밀, 꾸준함) |
| 방식 | 수동 관찰 | 매일 반복되는 같은 과제 |
| 놓치는 것 | 정신 피로(HRV가 수행과 어긋남) | 체력·심폐 |

## 출력 3단
| 단위 | 언제 | 출력 예 | 목적 |
|---|---|---|---|
| 주행 중 | 큰 편차일 때만, 정차 시 표시 | "평소보다 반응이 많이 늦습니다. 잠시 쉬어 가세요." | 안전 |
| 하루 | 주행 종료 후 | "오늘 평소 대비 −12%. 최근 21일 중 가장 낮습니다." | 자기 이해 |
| 몇 주 | 지속될 때만 | "3주째 평소 범위 아래입니다. 이동 범위도 줄었습니다. 컨디션을 점검해 보세요." | 변화 알림 |

## 하위 지표 3개
| 지표 | 무엇 | 신호(SDK) | 의존 |
|---|---|---|---|
| 반응 | 앞차 감속 → 내 브레이크 시작 지연 | ADAS 앞차 + `registerBrakePedalStatus` | ADAS 상세 미확인 |
| 정밀 | 조향 미세 보정의 크기·빈도, 차로 내 흔들림, 페달 재조정 | `registerSteeringWheelAngle`, ADAS 차선, 브레이크 페달 | 차로 흔들림은 ADAS |
| 꾸준함 | 같은 구간에서 매일의 조작 패턴 편차 | 위 신호 + FusedLocation 구간 매칭 | 위치 |

## 계산
1. 기준선: 같은 구간·비슷한 시간대의 최근 4~6주 기록(가정). 형성 전에는 출력 없음.
2. 오늘 값 = 기준선 대비 개인 표준편차 단위 → "최근 N일 중 몇 번째"로 표시.
3. 구간 난이도 보정(군집): 같은 구간·시간대 다른 차들의 오늘 편차를 뺀다. 남는 것 = 내 탓인 변화.
4. 표시 조건: 주행 10~15분 이상, 반복 구간 포함. 부족하면 "오늘은 측정 불충분".
5. 운전자 식별: 좌석 메모리 + 운전 패턴(문헌: 6분 내 식별).

## 표현 규칙
- 비교 대상은 항상 평소의 나. 타인·나이 비교 없음.
- 원인 단정 금지("피곤하다/우울하다" X). 사실("평소보다 느립니다") + 맥락은 질문형("어젯밤 잠이 부족했나요?").
- 진단·질병 용어 금지.
- 좋은 날도 보여 준다(하락 경고만 하는 앱이 되지 않게).
- 데이터는 차 안에 저장, 본인만 열람.
- 주행 중에는 숫자 없이 최소 표시, 안전 관련만.

## 근거 요약
- 피로: 반응 시간 +16.7%, 차로 흔들림 증가. PVT는 수면 부족 측정 표준(3분 버전도 민감).
- 우울: 실주행 특징만으로 고령자 우울 식별 AUC 0.84. 시뮬레이터에서 조향 반응 지연(중간 효과).
- 인지 저하: 실주행 데이터로 전임상 알츠하이머 AUC 0.96(나이·유전형 포함), 가속 페달 변동성이 강한 예측 변수.
- 시계 한계: 정신 피로 시 HRV가 수행 저하와 반대로 움직인 연구.
- 탈락: 인지 나이(개인차 > 나이 효과, 추정 오차 ±20년 이상, 거친 추정).

## 미확인 / 다음
1. ADAS SDK가 앞차·차선을 실시간 제공하는가 (반응·차로 흔들림 지표의 전제)
2. 조향각·브레이크 콜백 갱신 주기
3. 기준선이 몇 회 만에 안정되는가 (시뮬레이션)
4. 검증: 1인 자기 실험 — 수면 부족한 날 점수가 실제로 떨어지는지

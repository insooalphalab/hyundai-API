# 근거: 몸의 반응으로 운전자 상태를 파악하는 연구·기술 (2026-10-28)

> CONCEPT_v3_integrated.md 핵심 원칙("본인의 판단이 아니라 몸이 실제로 반응한 지점")과 "평소의 나" 모듈의 근거 자료.
> 수치는 각 출처의 보고값이며, 대부분 소수 참가자·시뮬레이터·짧은 구간에서 나온 값이라 일반 운전자·실도로에서는 낮아질 수 있음.

## 1. 결론
- **졸음:** 이미 양산 (조향 기반, 운전자 카메라 기반).
- **음주·저혈당·인지 저하:** 실차 검증된 연구 단계.
- **스트레스·인지 부하:** 실험실 정확도는 높으나 실도로 일반화 약함.
- **접촉식 생체 센서(핸들 심전도 등):** 실도로에서 신호 확보는 되나 일상 사용성·잡음 문제가 남음.

## 3. 실현 가능성을 가르는 요인
1. **정확도 수치의 함정:** 소수 참가자·시뮬레이터·짧은 구간의 값. 처음 보는 운전자·실도로에서 떨어짐. 오경보가 잦으면 사용자가 기능을 끔.
2. **행동 신호는 늦고 생리 신호는 빠름:** 조향 등 차량 조작은 상태가 꽤 나빠져야 변함(음주 연구). 시선·심박은 일찍 변하지만 센서 필요. 대신 차량 조작 신호는 SDK만으로 얻음.
3. **여러 신호 결합이 우수:** 다중 신호가 단일보다 일관되게 나음(주의분산 F1 96%, 졸음 96%) → 생성 규칙 1번과 같은 결론.
4. **개인 기준선 필요:** 심박·조향 습관의 정상 범위가 사람마다 다름 → 연구 흐름도 개인 적응 쪽, "평소의 나"와 같은 방향.
5. **데이터 사용 제약:** EU 규정상 운전자 카메라 데이터는 차 안 처리(기억 기반, 원문 미확인). 생체·건강 추론은 민감정보.

## 4. 개념에 주는 의미
| 단계 | 쓸 수 있는 것 | 근거 수준 |
|---|---|---|
| Pleos SDK만 | 조향·브레이크로 졸음·피로, 장기 변화(평소의 나) | 양산 사례(벤츠) → 현실성 높음 |
| + PEX 카메라 | 졸음 정확도 향상, 음주 초기 징후, 주의분산 | 양산·실차 연구 |
| + PEX 레이더·접촉 센서 | 심박·호흡(자는 가족 감지, 운전자 스트레스) | 시제품 수준, 보조로만 |

→ "평소의 나"는 졸음·피로처럼 검증된 신호로 시작하고, 나머지는 PEX와 함께 단계적으로 넓힌다.
